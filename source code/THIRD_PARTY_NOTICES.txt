FFmpeg
------
This copy of PubHorror includes ffmpeg.exe and ffprobe.exe from FFmpeg
version 9.0.2, "essentials" build by gyan.dev (https://www.gyan.dev/ffmpeg/builds/).

FFmpeg is licensed under the GNU General Public License version 3. The full
license text is in ffmpeg-LICENSE.txt in this folder.

PubHorror runs FFmpeg as a separate program. FFmpeg has not been modified.

Source code: the complete source for FFmpeg 9.0.2 (ffmpeg-9.0.2.tar.xz) is
attached to every PubHorror release at
  https://github.com/TrinketGoblin/PubHorror/releases
and is also on the itch.io download page. The build configuration and the list
of libraries included in this build are published by gyan.dev at the link above.
Upstream FFmpeg: https://ffmpeg.org

MakeMKV
-------
MakeMKV is not included with PubHorror. If you install it yourself, PubHorror
can use it to read discs you own. MakeMKV is made by GuinpinSoft inc. and is
covered by its own license: https://www.makemkv.com


OpenDyslexic font
-----------------
PubHorror uses the OpenDyslexic font (version 0.990, by Abbie Gonzalez,
https://opendyslexic.org) in the app and on the phone page. It is licensed
under the SIL Open Font License 1.1; the full text is at the end of this file.
The font files are included unmodified.

Node.js (sharing component)
---------------------------
PubHorror's optional "Share my library" / Watch Party feature runs a small
server with Node.js, which is included as sidecar\node.exe (official, unmodified
Windows build v24.11.0 from https://nodejs.org). Node.js is licensed under the
MIT license; it bundles other open-source components (V8, libuv, OpenSSL, ICU
and others) whose licenses are all reproduced in node-LICENSE.txt in this folder.

Node.js packages used by the sharing component
----------------------------------------------
All MIT licensed. Each package's license file is also kept in
sidecar\node_modules\<package>\LICENSE. Full texts follow at the end.
  @leichtgewicht/ip-codec 2.0.5   MIT   https://github.com/martinheidegger/ip-codec.git
